Which voice engine sounds best?

These are real renders of the same paragraph. The radio is now set to MLX-Audio (sample 5); Phonon remains the host reference voice. Motion Graphics also uses Phonon, so it does not add a separate TTS engine.

1. Phonon reference / motion graphics

The voice reference currently used for Nocturnal Animal. Warm and dramatic, but limited as a final narration voice.

2. VoiceStudio OmniVoice — cloned host baseline

The actual engine and cloned host profile used by ETMW Radio AI today. This is the baseline to beat.

3. VoiceStudio OmniVoice — native design voice no Phonon

A voice designed inside VoiceStudio, with no Phonon reference. This is the most direct way to move away from the Phonon timbre.

4. VoiceStudio KittenTTS fast · preset

Lightweight English preset voice. Fast and clear, but it cannot clone a host voice or use a reference profile.

5. VoiceStudio MLX-Audio selected · Apple Silicon

The MLX-Audio Kokoro preset. This is the selected radio voice. In this configuration it uses a preset voice, so hosts will share it; cloning needs the CSM model selected in VoiceStudio.

How to switch engines:
Set VOICE_STUDIO_ENGINE=mlx-audio (selected), omnivoice (cloned host), or kittentts in the radio server environment. To try the native design voice for every host, set VOICE_STUDIO_PROFILE_OVERRIDE=e2764a03. Phonon remains available and is not removed.
